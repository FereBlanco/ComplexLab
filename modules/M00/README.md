## 1. Temática

Dejar el proyecto completamente operativo: conexiones (Jira, Git, Unity, Blender), convenciones técnicas y ecosistema Claude. **Módulo sin código** — sus features producen configuración verificada y documentación, no software. El ciclo de vida se adapta: las fases de implementación/pruebas se sustituyen por ejecución/verificación, y el contrato define entregables y criterios de aceptación igualmente.

## 2. Objetivos de aprendizaje

- Método: crear y gestionar épicas, historias y subtareas en Jira desde Claude.
- Herramientas: pipeline completo Jira + Git + Unity + VS Code + Claude Code.
- Claude: conectores (MCP), skills propias, CLAUDE.md por carpeta.
