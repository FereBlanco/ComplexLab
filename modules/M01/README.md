## 1. Temática

Autómatas celulares como primera puerta a la vida artificial y la emergencia: reglas locales simples que producen comportamiento global complejo. Pieza central: el Juego de la Vida de John Conway.

## 2. Objetivos de aprendizaje

- Científicos: emergencia, autoorganización, universalidad computacional del Game of Life, clases de comportamiento de Wolfram.
- Unity/patrones: separación simulación/render, state machine, object pooling vs. texturas, doble buffer de estado.
- Claude/método: completar el primer ciclo SDD entero (contrato → Code → tests → conclusiones) y el flujo Cowork ↔ Code.
